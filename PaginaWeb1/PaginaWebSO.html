Protección y Seguridad en los Sistemas Operativos

Conoce los mecanismos, herramientas y técnicas que permiten proteger los sistemas operativos, controlar el acceso a los recursos y mantener segura la información.

Explorar los temas

Introducción

La protección y seguridad son elementos fundamentales de los sistemas operativos. Su función principal es evitar accesos no autorizados, proteger los datos y garantizar que los recursos de una computadora sean utilizados correctamente.

🔐

Protección

Controla cómo los usuarios y programas pueden utilizar los recursos del sistema.

🛡️

Seguridad

Busca evitar amenazas, ataques y situaciones que puedan comprometer la información.

💻

Sistemas operativos

Administran el hardware, los programas, los usuarios y los recursos de la computadora.

6.1. Concepto y objetivos de protección y seguridad

La protección y seguridad en un sistema operativo consiste en establecer mecanismos que permitan controlar el acceso a los recursos y defender la información contra posibles amenazas.

Confidencialidad

Garantiza que la información solamente pueda ser consultada por personas autorizadas.

Integridad

Evita que los datos sean modificados, eliminados o alterados sin autorización.

Disponibilidad

Permite que los usuarios autorizados puedan acceder a los recursos cuando los necesiten.

Objetivo principal: mantener los recursos del sistema protegidos, garantizar el funcionamiento correcto y evitar que personas no autorizadas puedan acceder a la información.

6.2. Clasificación aplicada a la seguridad

La seguridad informática puede clasificarse de diferentes maneras, dependiendo del tipo de protección que se necesita y del momento en que se aplica.

🏢

Seguridad física

Protege los equipos e instalaciones contra robos, incendios, daños y accesos físicos no autorizados.

🔒

Seguridad lógica

Protege los programas, archivos, cuentas de usuario y datos mediante contraseñas, permisos y controles de acceso.

📋

Seguridad administrativa

Establece políticas, procedimientos y reglas para administrar correctamente la seguridad.

🛡️

Seguridad preventiva

Busca evitar incidentes mediante actualizaciones, controles de acceso y medidas de protección.

🔎

Seguridad detectiva

Identifica actividades sospechosas mediante registros, monitoreo y sistemas de detección.

🔧

Seguridad correctiva

Permite corregir fallas y recuperar el sistema después de un incidente de seguridad.

6.3. Funciones del sistema de protección

El sistema de protección de un sistema operativo administra los permisos y establece reglas para garantizar que cada usuario o proceso utilice únicamente los recursos que tiene autorizados.

Autenticación

Comprueba la identidad del usuario mediante contraseñas, huellas digitales u otros métodos.

Autorización

Determina qué acciones puede realizar cada usuario dentro del sistema.

Control de acceso

Restringe el acceso a archivos, carpetas, dispositivos y aplicaciones.

Auditoría

Registra las actividades realizadas para identificar posibles problemas de seguridad.

Ejemplo: En Windows, un administrador puede permitir que determinados usuarios modifiquen un archivo, mientras que otros solamente pueden leerlo.

6.4. Implantación de matrices de acceso

Una matriz de acceso es un modelo que representa los permisos que tienen los usuarios o procesos sobre diferentes objetos del sistema.

Ejemplo de una matriz de acceso

Usuario Archivo 1 Archivo 2 Impresora
Administrador Leer / Escribir Leer / Escribir Usar
Profesor Leer / Escribir Leer Usar
Estudiante Leer Sin acceso Sin acceso

Lectura

Permite consultar el contenido de un archivo sin modificarlo.

Escritura

Permite modificar o guardar información en un archivo.

Ejecución

Permite ejecutar un programa o aplicación.

Importancia: las matrices de acceso ayudan a organizar los permisos y evitan que los usuarios realicen operaciones para las que no tienen autorización.

6.5. Protección basada en el lenguaje

La protección basada en el lenguaje utiliza características de los lenguajes de programación para controlar el acceso a los datos y prevenir operaciones no permitidas.

Encapsulamiento

Protege los atributos de una clase y permite acceder a ellos mediante métodos controlados.

Control de tipos

Evita operaciones incorrectas entre diferentes tipos de datos.

Modificadores de acceso

Permiten establecer quién puede utilizar una clase, método o atributo.

Ejemplo en C#: 
public class Cuenta
{
    private double saldo;

    public void Depositar(double cantidad)
    {
        if (cantidad > 0)
        {
            saldo += cantidad;
        }
    }

    public double ConsultarSaldo()
    {
        return saldo;
    }
}
El atributo saldo es privado, por lo que no puede modificarse directamente desde fuera de la clase. Se utilizan métodos para controlar su acceso.

6.6. Validación y amenazas al sistema

La validación consiste en comprobar que los usuarios, programas y operaciones cumplen con las reglas establecidas por el sistema operativo.

👤

Validación de usuarios

Comprueba que la persona que intenta ingresar tenga una identidad autorizada.

📁

Validación de permisos

Verifica si un usuario tiene autorización para acceder a un recurso.

⚙️

Validación de procesos

Comprueba que los programas realicen operaciones permitidas.

Principales amenazas al sistema

Virus informáticos

Programas maliciosos que pueden infectar archivos y afectar el funcionamiento del equipo.

Troyanos

Programas que aparentan ser legítimos, pero realizan actividades maliciosas.

Phishing

Técnica que busca engañar a los usuarios para obtener contraseñas o información confidencial.

Ransomware

Malware que bloquea o cifra archivos para exigir un pago por su recuperación.

Acceso no autorizado

Ocurre cuando una persona ingresa a un sistema sin tener los permisos correspondientes.

Denegación de servicio

Ataque que busca interrumpir la disponibilidad de un servicio o sistema.

6.7. Cifrado

El cifrado es un procedimiento que transforma información legible en un formato que no puede comprenderse fácilmente sin la clave adecuada. Su objetivo es proteger la confidencialidad de los datos.

Cifrado simétrico

Utiliza la misma clave para cifrar y descifrar la información.

Ejemplo: AES.

Cifrado asimétrico

Utiliza dos claves relacionadas: una pública y otra privada.

Ejemplo: RSA.

¿Por qué es importante? El cifrado protege contraseñas, documentos, comunicaciones y datos personales frente a personas que no tienen autorización.

Conclusión

La protección y seguridad en los sistemas operativos son indispensables para mantener la información segura y garantizar el correcto funcionamiento de los equipos. Mediante mecanismos como el control de acceso, la autenticación, la validación y el cifrado, es posible reducir los riesgos y proteger los recursos informáticos.

La seguridad no depende de una sola herramienta, sino de la combinación de diferentes mecanismos, políticas y buenas prácticas.
